# 大羅一炁、三炁生成與中心軸繞行更新

本次將生成內容加入大羅與三清節點的三種閱讀模式，以及完整專題論述；保留原有宇宙配色、四宮、五氣、三清三角與頁內文獻出處。

- 層級維持第五層三清、第六層大羅；六層是介面教學分類。
- 大羅頁面新增一炁生成、三天三境、九炁九天例目與九壘脈絡。三清圖的源頭標為大羅一炁，並以光脈銜接第六層；此連接是跨文本教學示意，《業報因緣經》該段原詞仍是一炁。
- 模式 A 保留始炁／元炁／玄炁配清微／禹餘／大赤的原有 3D 對應。模式 B 在頁內獨立對讀王契真卷五十四的玄／元／始順生與配天；不將未載色象移入模式 B。模型色彩為教學設計，另表列青、白、黃等文本色象。
- 分別呈現 28＋4＋3＋1＝36 的垂直層級整理、9＋9×3＝36 的九重衍生讀法示意，以及王契真卷五十四仍待校勘的二十七天相關語句。不同文本計數不可拼為同一總表。
- 點選靈寶各層與三清／四宮物件時，相機繞固定中心軸，以角度、半徑及高度過渡聚焦；使用最短角度路徑，避免直線穿越中心。重複正面選取也有輕微轉動。支援減少動態偏好；其餘星盤保留原有聚焦方式。
- 沿用遮擋物暫時淡化、重疊徽章暫時隱藏與關閉後還原。文獻僅在頁內顯示，不跳轉其他網頁。

## 來源與限制

電子轉錄初核：《靈寶無量度人上經大法》卷四〈訓釋經義品〉、王契真《上清靈寶大法》卷五十四〈天上三十六〉及卷十〈玄穹主宰〉、《洞玄靈寶自然九天生神章經》〈三寶大有金書〉及前三生神章。

董思靖《解義》引《三天正法經》的色象與一分為三說已找到檢索線索，原書及底本影像仍待核對。生成樞紐、能量源泉與復歸歸宿等為現代分析語言，炁不等於現代物理學能量。新內容不宣稱是全道藏一致的宇宙生成史。其餘既有材料未在本次全面重校。

## 使用

套件內含 vendor/ 與授權檔，整包放入同一靜態網站目錄即可；不需上傳 node_modules/。本次未發布線上網站。

本機執行 python -m http.server 8000（Windows 可用 py），開啟 http://localhost:8000 。請勿直接以 file:// 開啟，以免 JSON 載入受阻。

安裝及回歸檢查：npm ci；npx playwright install chromium；npm test。可用 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH 指向現有 Chromium。測試包含中心軸圓弧軌跡、各層聚焦、三清及四宮點選、兩種生成模式與計數卡片、30 節點的三種閱讀模式、無外部文獻連結、手機閱讀區及視窗關閉。測試截圖產生於 test-results/。

樣式更新：npm run build:css。

第三方：Three.js / OrbitControls 0.128.0、TWEEN 18.6.4、Tailwind CSS 3.4.17，均為 MIT 授權，見 vendor/。
