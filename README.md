# 道教宇宙空間：第四層、閱讀模式與聚焦更新

本版包含前版五方造型、三清三角配置、宇宙色閱讀卡片，並新增以下功能：

- 三種閱讀模式各有用途提示、選取狀態與鍵盤方向鍵操作。未選節點時，切換模式會開啟目前主題的第一個節點。導讀呈現問題／概念／材料與完整論述；課程呈現脈絡／書目／比較；考證呈現來源／異文線索／核對狀態。
- 文獻出處一律在頁內顯示為文字，內容卡與專題視窗不再產生外部文獻超連結。
- 選取圖示時以該物件的世界座標聚焦；徽章優先繪製，重疊徽章暫時隱藏，前景遮擋物淡化。切換節點或關閉後還原。修正徽章浮動混用局部與世界座標的問題，並避免重複更新共用徽章；長標題自動換行。
- 第四層加入四天、四宮、垂直位階、清淨炁、避劫與劫後再造的內容，並新增四方宮闕示意。三種模式分別提供概念閱讀、研讀順序與來源核對紀錄；可逐宮點選。

學術處理：王懸河《三洞珠囊》卷七〈三十二中法門名數品〉電子轉錄支持四天名目、四宮並列與所引《太真科》的種民／王母迎接脈絡；底本影像尚未核對。逐一四方配宮、清淨炁環境、三災範圍與具體再造程序分項標為待核。移除原檔第四層未確認的《度人經》直接引句，修正原有天名。四梵天的稱謂、太極／大極等字樣仍須依文本與版本辨析。其餘既有學術內容未在本次全面考證。宮闕、三角與天文核心皆為教學示意，不是古籍圖像復原。

## 使用與驗證

整包包含 vendor/ 及授權文字；替換網站檔案並保留相對路徑，不需上傳 node_modules/。本次未發布線上網站。

本機執行 python -m http.server 8000（Windows 可用 py），再開啟 http://localhost:8000 。請不要直接使用 file:// 開啟，以免 JSON 讀取受阻。

驗證包含完整 WebGL 場景、全部 30 節點的聚焦投影位置及三種閱讀模式、三清點選、四宮點選、文獻無外部連結、模式鍵盤切換、無節點時切換模式、中央與南方徽章不重疊、手機底部閱讀區、Escape 關閉與相機還原。使用 Chromium / SwiftShader；不能保證任意手動旋轉角度都保持全部物件可見，但選取後會執行聚焦與遮擋處理。

重跑：npm ci；npx playwright install chromium；npm test。可設定 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH 指向現有 Chromium。截圖產生於 test-results/。更新 Tailwind 樣式使用 npm run build:css。

Third-party: Three.js / OrbitControls 0.128.0、TWEEN 18.6.4、Tailwind CSS 3.4.17；均為 MIT 授權，見 vendor/。
