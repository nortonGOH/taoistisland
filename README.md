# 五方五氣貫穿六層：由上而下的宇宙架構

## 本次配置

依本次指定，六層由上而下編號：

1. 無上大羅天。
2. 三清勝境。
3. 四種民天與三界二十八天，合為三十二天；欲界、色界、無色界為此層的內部分區，五劫天輪亦在此組。
4. 三光與神州大地，展開五星、五嶽、五臟的天—地—人對應。
5. 地下九壘與三十六土皇。
6. 浩蕩頑空、元始梵風與剛風風澤。

新增第六層剛風的獨立可點選節點，全站共 34 個節點。三清三角、五劫天輪與宇宙配色保留。

五方五氣本體盤已移入主塔，與其共軸，置於第三層下緣與第四層之間（主塔局部 Y=-2.6），保留原造型。五氣光脈穿過本體盤，再連接第四層；主塔包含五條跨層光脈、一個共同源頭及 25 個可點選跨層節點。點選後依主塔中心軸聚焦，對應光脈高亮、頁內標示所在層；關閉後還原。第三、第四層的核心顯化在頁內分區說明。

## 頁內資料與證據限制

跨層面板附六層導覽、五方天名、五星／五嶽／五臟對照、五方國土、金允中青黃白三炁與三境三田的另一組對應，以及中央一／十／十二氣的分讀。原有三炁模式 A、B 不被這組宋代齋壇存炁說覆蓋。

電子轉錄初核：《元始五老赤書玉篇真文天書經》卷上有五帝真符與五星、五臟、五嶽的關係；中央章題另見一十二炁黃天。金允中《上清靈寶大法》卷二十一〈臨壇符法品〉見青—玉清—上田—肝、黃—上清—中田—脾、白—太清—下田—肺。

中央本體盤仍顯示一氣；十氣保留為提供數目待核，十二氣另按真文經電子章題列出。常山／恒山等字樣、完整配對與底本異文尚待核對。提供的 passage 19、23、34 等沒有對應原檔與定位，不能作正式引用；五方國土與主神配對也保留待核。

六層分組、貫通光脈與顯化重點是本圖的教學整理，不宣稱各部經典逐字共有同一六層表，也不把光脈當成史料已證的物理傳輸路徑。五臟屬原有宇宙對應語言，不直接等同現代器官生理學。

## 使用與驗證

套件包含 vendor/ 及授權檔。保留檔案相對路徑，整包替換靜態網站目錄；不需上傳 node_modules/。本次未發布至線上。

本機執行 python -m http.server 8000（Windows 可用 py），開啟 http://localhost:8000 。請勿以 file:// 開啟，以免 JSON 載入受阻。

回歸檢查：npm ci；npx playwright install chromium；npm test。可用 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH 指向既有 Chromium。測試驗證六層排名、五條光脈、25 個跨層節點的點選、本體盤的主塔父層與交界座標、高亮與還原、三界 6／18／4 刻度、34 節點聚焦與三種閱讀模式、三清與四宮點選、手機版、視窗關閉及無外部文獻連結。截圖在 test-results/。

更新樣式：npm run build:css。

Third-party: Three.js / OrbitControls 0.128.0、TWEEN 18.6.4、Tailwind CSS 3.4.17；均為 MIT 授權，見 vendor/。

本體盤交界位置為教學配置，並非第七層。「三五合和」與五臟存思通達五老之說保留為跨文本解讀，具體修法與文本定位待核。點選本體盤五方徽章亦沿主塔中心軸旋轉並聚焦。
