# 靈寶六層主塔重排與五劫天輪移位

## 本次配置

五劫天輪已由右側移至靈寶主塔，並成為主塔的子群組，與主塔共用中心軸。右側五方五氣本體盤使用獨立座標，位置與既有造型不變。

第一層：欲界六天。第二層：色界十八天。第三層：無色界四天。三者合為三界二十八天。

第四層：種民天／四梵天；保留四天四宮與避劫斷界。第五層：三清三角勝境。第六層：大羅與玉京景觀。

原凡俗世界與地下九壘保留為主塔下方器界、基座，不再占用第一、第二層的編號。新增三個可搜尋與點選的三界分層節點，連同三界總覽，共 33 個節點。劫期與各天層的鏡頭皆繞主塔中心軸聚焦。

## 新增說明與證據限制

第四層加入齋法、服食符圖、經籍保舉、陽九百六受度及劫後善種的修持路徑。《天地運度自然妙經》有明運度、長齋與誦經避災的電子轉錄線索；《三洞珠囊》引《太真科》有種民受迎脈絡。尚未逐項確認服符、保舉及昇入四天的組合，因此不把三項並列資格寫成所有靈寶經通行的排他條件。

第五、六層新增從南北朝至隋唐教理統攝理解靈寶濟度與上清真境的歷史解釋方向，以及形神純化、退去質礙、趨向元始虛無的修行品位解讀。《道教義樞》卷一〈位業義〉、卷七〈三界義〉為對讀材料；年代、文本層次及逐項位階對應仍待考證。不將新幾何配置宣稱為單一古經的原圖。

三界與天地劫運的關係仍在頁內呈現。既有赤書／劫名疑義、各劫生成與毀壞的不同功能，以及精爽留存與修持例外的辨析保留，不將所有劫名都當成同一毀滅事件。

## 使用與驗證

整包包含 vendor/ 與授權檔。保持檔案相對路徑，替換靜態網站目錄；不需上傳 node_modules/。本次未發布至線上。

本機以 python -m http.server 8000 啟動（Windows 可用 py），開啟 http://localhost:8000 。請不要使用 file:// 開啟，以免 JSON 讀取受阻。

重跑：npm ci；npx playwright install chromium；npm test。可設定 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH。測試驗證五劫天輪的父群組與世界座標、五方五氣座標保持原值、前三層高程與刻度 6／18／4、33 節點的聚焦與三種閱讀模式、中心軸軌跡、三清與四宮點選、手機版及無外部文獻連結。測試圖存於 test-results/。

原有五方形狀、三清模式 A／B 對讀與大羅生成脈絡均保留。閱讀卡維持宇宙配色，文獻出處只在頁內顯示。

第三方：Three.js / OrbitControls 0.128.0、TWEEN 18.6.4、Tailwind CSS 3.4.17，均為 MIT 授權，見 vendor/。
